# Phasing — Masoko + OMB 2024 VCF

This step phases the biallelic, PASS-filtered SNP set for the wild-caught Masoko
individuals using [Eagle](https://alkesgroup.broadinstitute.org/Eagle/).

## Input

Per-chromosome biallelic, PASS-only SNP BCFs produced in the previous step:

```
Masoko_biallelic_pass_snps_mean6600_DP30_Q20_GQ30_MM10.<chrom>.bcf.gz
```

(subset of `Masoko_biallelic_pass_snps_mean6600_DP30_Q20_GQ30_MM10.bcf.gz`,
5,395,321 SNPs genome-wide, filtered with `bcftools view -v snps -f PASS`)

## Working directory

```bash
cd masoko_biallelic
mkdir phase_pass_only
cd phase_pass_only
```

## Genetic map

Phasing used the Masoko fine-scale genetic map (per-chromosome Eagle-format
files: `benthicSamplesN89_eagle_chr<N>.map.zst`), located at:

```
~/rds/rds-durbin-group-8b3VcZwY7rY/projects/cichlid/massoko/genetic_map/
```

Per the map's own `README.map`:

- **Generated by:** Milan Malinsky, 07/10/19
- **Samples used:** all 89 benthic individuals (individuals with PC1 < -0.06
  in the April 2018 PCA, out of a total n=336)
- **Scaling:** scaled to match the cM length of linkage groups reported in
  O'Quin et al., 2013
- **Software:** LDhat v2.2
- **Parameters:** `-its 20000000 -samp 20000 -bpen 5`
- **Likelihood file:** precomputed, assumes theta = 0.001
- **MCMC:** first 10,000,000 iterations discarded as burn-in; map averaged
  over the second 10,000,000 iterations
- **Windowing:** run in windows of 25,000 SNPs with 2,500 SNP overlap at each
  end; overlaps trimmed and windows concatenated back together

The directory also contains helper/conversion scripts (`ldhat2eagle.pl`,
`ldhat2plink.pl`, `txt2map.pl`, `conversion.sh`) used to convert the LDhat
output into Eagle's expected map format — not needed to rerun phasing itself,
but kept for provenance.

> **Note:** this map was built from *benthic* Lake Malawi individuals (N=89),
> not from the Masoko samples being phased here — i.e. it is an external
> recombination map applied to the Masoko dataset, not one derived from it.

## Step 1 — Run Eagle per chromosome

```bash
sbatch sbatch_phase_pass.sh
# Submitted batch job 59053786
```

**Script:** `sbatch_phase_pass.sh` — SLURM job array, one task per chromosome
(`--array=1-20,22-23`, i.e. chr1–chr20 and chr22–chr23; chr21 and any chr24+
excluded/not present in this callset). Run on `icelake-himem`, 4 cpus/task,
24h time limit, `OMP_NUM_THREADS=1`.

For each array task (`chr${SLURM_ARRAY_TASK_ID}`):

1. **Subset to PASS sites for that chromosome only**, from the full biallelic
   PASS-filtered callset:
   ```bash
   bcftools view -f PASS -r ${CHRN} -O z -o $TMPVCF $BCF
   tabix -p vcf $TMPVCF
   ```
   where `$BCF` = `masoko_biallelic/Masoko_biallelic_pass_snps_mean6600_DP30_Q20_GQ30_MM10.bcf.gz`

2. **Phase with Eagle:**
   ```bash
   eagle --vcf=$TMPVCF \
         --geneticMapFile=$MAPFILE \
         --outPrefix=$OUTFILE \
         --Kpbwt=40000 \
         --expectIBDcM=0.5 \
         --noImpMissing \
         --vcfOutFormat=z \
         --numThreads=4 \
         >> $LOG 2>&1
   ```
   - `$MAPFILE` = `genetic_map/benthicSamplesN89_eagle_${CHRN}.map` (see [Genetic map](#genetic-map) above)
   - `$OUTFILE` = `phase_pass_only/Masoko_biallelic_pass_snps_phase_${CHRN}`
   - **No external reference panel** (`--vcfRef` not used) — this is
     population-based (reference-free) phasing using the Masoko samples
     themselves as the phasing panel, with an external genetic map for
     recombination distances
   - `--noImpMissing` — missing genotypes are not imputed, only phased
   - `--Kpbwt=40000` — number of conditioning haplotypes in the PBWT (Eagle default is lower; increased here)
   - `--expectIBDcM=0.5` — expected IBD segment length parameter (Eagle default)
   - Log: `phase_pass_only/logs/malawi_cichlids_v3_pass_phase_${CHRN}.log`

3. **Index the phased output:**
   ```bash
   tabix -p vcf ${OUTFILE}.vcf.gz
   ```

4. **Clean up** the per-chromosome temporary PASS-only VCF (`$TMPVCF`).

Output per chromosome: `Masoko_biallelic_pass_snps_phase_${CHRN}.vcf.gz` (+ `.tbi`)

## Step 2 — Rerun with explicit paths

```bash
sbatch sbatch_phase_pass_rerun.sh
# Submitted batch job 59056293
```

**Script:** `sbatch_phase_pass_rerun.sh` — identical SLURM setup and Eagle
command to `sbatch_phase_pass.sh` above, with two differences:

1. **Path fix:** all paths (`$BCF`, `$TMPVCF`, `$MAPFILE`, `$OUTFILE`, `$LOG`)
   were changed from `~/rds/...` to the explicit
   `/home/bef22/rds/rds-durbin-group-8b3VcZwY7rY/...` form. The script itself
   notes why: `# Note: these must include /home/bef22/ ~/ doesn't work!` —
   `eval`-ing a command containing an unexpanded `~` inside a variable does
   not reliably tilde-expand on the compute node, so the first run's paths
   silently failed to resolve.
2. **PASS-subsetting step skipped:** the `bcftools view -f PASS` /
   `tabix` block from Step 1 is commented out in the rerun, since the
   per-chromosome PASS-only temporary VCFs (`$TMPVCF`) had already been
   created successfully in Step 1 and just needed to be re-used — only the
   Eagle phasing step itself needed rerunning.

Eagle command (unchanged from Step 1):

```bash
eagle --vcf=$TMPVCF \
      --geneticMapFile=$MAPFILE \
      --outPrefix=$OUTFILE \
      --Kpbwt=40000 \
      --expectIBDcM=0.5 \
      --noImpMissing \
      --vcfOutFormat=z \
      --numThreads=4 \
      >> $LOG 2>&1
```

Followed by indexing (`tabix -p vcf ${OUTFILE}.vcf.gz`) and removal of the
temporary PASS-only VCF.

## Step 3 — Merge phased chromosomes into a genome-wide VCF

```bash
sbatch -A DURBIN-SL2-CPU -p icelake --time=12:00:00 --ntasks=1 \
  --wrap="bcftools concat -f phasedBcfList.txt -O z -o Masoko_biallelic_pass_snps_phase_genome.vcf.gz"
# Submitted batch job 59153660
```
